# Mars Racer

A Cybertruck race around Jezero Basin. Open the dev server and drive.

```bash
npm install
npm run dev
```

Then open http://127.0.0.1:5173/

The published build is at https://fubak.github.io/mars-racer/

W A S D drive, Space slides, R resets.

The truck mesh is [Tesla Cybertruck](https://skfb.ly/6QSBr) by hashikemu, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Live critic notes are on [progress.html](http://127.0.0.1:5173/progress.html) while the dev server is running. To resume the screenshot loop in a new session, read `docs/critic-handoff.md`. Round 916 scored the sky, terrain, dust, and HUD. The next round is 917.
